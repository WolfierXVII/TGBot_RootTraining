# TGBot_RootTraining

Telegram-бот для обучения устному счёту приближённых квадратных корней
с помощью вавилонского метода.

## Функционал
- 📚 Пошаговое обучение (вавилонский метод)
- 📝 Задачи с таймером, адаптивная сложность
- 👤 Личный кабинет со статистикой
- 🏆 Топ-10 игроков

## Стек
Python 3.14, aiogram 3, SQLite (aiosqlite)

## Запуск
1. Установить зависимости: `pip install aiogram aiosqlite`
2. Создать `src_private.py` с `bot_token = "твой_токен"`
3. Запустить: `python main.py`
